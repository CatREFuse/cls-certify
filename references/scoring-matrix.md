## 评级标准

| 总分 | 评级 | 说明 |
|:----:|:----:|------|
| 90-100 | S+ | 顶级安全，通过人工验证 |
| 80-89 | S | 优秀，满足所有安全要求 |
| 65-79 | A | 标准级，可放心使用 |
| 50-64 | B | 基础级，存在改进空间 |
| 30-49 | C | 警示级，存在安全风险 |
| 0-29 | D | 危险级，不建议使用 |

## 评级判定流程

```
开始
  ↓
发现 D 级触发项? ──是──→ D 级
  ↓ 否
发现 C 级触发项? ──是──→ C 级
  ↓ 否
总分 ≥ 65? ──否──→ B 级
  ↓ 是
满足 A 级所有要求? ──否──→ B 级
  ↓ 是
T1/T2 来源? ──否──→ A 级
  ↓ 是
满足 S 级额外要求? ──否──→ A 级
  ↓ 是
通过人工验证? ──否──→ S 级
  ↓ 是
S+ 级
```

## 意图验证判定

Agent 对工具候选命中做出判定：

| 判定 | 含义 | 计分 |
|------|------|------|
| confirmed | 确认恶意，实际执行危险操作 | 原始严重性，触发强制降级 |
| confirmed_low_risk | 确认存在但用途合法 | -15，不强制降级 |
| false_positive | 误报（文档描述/引用） | 排除不计分 |
| low_risk | 测试/示例代码引用 | -5 |
| comment | 注释中的说明文字 | 排除不计分 |

### 判定依据

- `.md` 文件反引号中 → 高概率误报
- 列表项（`- 检测 eval()`）→ 高概率文档描述
- `.js/.py/.sh` 非注释行 → 高概率真实威胁
- 周围有 "检测"/"check"/"detect"/"scan" → 高概率误报

### Agent 上下文注入判定指引

- `.claude/memory` 在文档说明中 → false_positive
- `.claude/memory` 在代码路径操作中 → confirmed
- `CLAUDE.md` 在文档引用/示例中 → false_positive
- `CLAUDE.md` 在 Write/Edit 目标参数中 → confirmed
- Skill 为管理器/配置工具且合法访问 `.claude/` → confirmed_low_risk
- ANSI 转义用于 CLI 彩色输出 → confirmed_low_risk
- ANSI 转义在动态构造中 → confirmed
